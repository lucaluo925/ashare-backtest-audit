# A 股回测制度规则审计器

**一个问题：你的回测里，有多少笔成交在实盘根本成交不了？**

2016–2026 全样本，当日涨幅 ≥9.8% 的股票日共 176,533 个，
其中 **145,079 个（82.2%）收盘封在涨停价上** —— 挂单排在几万手后面，买不进。

任何"大涨当天收盘买入"的短线策略，八成以上的成交在实盘不存在。
而多数回测框架不查这件事。

---

`600000.XSHG`、`SH600000` 还是裸 `600000` 都能认。

只有逐日持仓、没有成交明细？


## 它查什么（十七项）

| 检查 | 问题 | 为什么重要 |
|---|---|---|
| `limit_fill` | 涨停日买入 / 跌停日卖出 | 回测成交了，实盘成交不了 → **高估收益** |
| `open_limit_fill` | **开盘**涨停日买入 / 跌停日卖出 | 按开盘价成交的引擎看这一项；与上一项**互补，不要相加** |
| `limit_rule` | 涨跌幅是否按**当日生效的规则**取 | 创业板 2020-08-24 才从 ±10% 放宽到 ±20% |
| `stamp_duty` | 印花税是否分段 | 2023-08-28 减半；**2008-09-19 之前是双边征收** |
| `circuit` | 2016-01-04 / 01-07 熔断日 | 这两天 `tradestatus` 仍为 1，多数面板判它可交易 |
| `t1` | 当日买入是否当日卖出 | A 股 **T+1**；通用框架默认 T+0，拿来跑 A 股不会有任何提示 |
| `suspension` | 是否在停牌日成交 | 那天根本没有交易 |
| `held_through_suspension` | 持仓是否穿越了停牌期 | 那段时间账面在算收益，而你既不能卖也不能止损 |
| `price_convention` | 成交价是原始价还是复权价 | 复权价不是任何一天真实的报价，涨停价/股数/价格阈值都会错 |
| `cost_floor` | 成本假设是否低于监管费用地板、有没有佣金起点 | 过户费/经手费/证管费三项双边约 1.3bp 一轮；**佣金起点 5 元**在小单上让费率翻倍 |
| `order_size` | 整手约束、单笔申报上限、ST 单日 50 万股买入上限 | 按权重回测的策略落地要取整：一只 300 元的股票一手 3 万元 |
| `tick_size` | 成交价是否落在 0.01 元的最小变动单位上 | 不落在分上的价格在市场上不存在 —— 说明你成交在均价而非可申报价 |
| `naked_short` | 卖出手里没有的票 | **A 股裸卖空不存在** —— 多空/截面做空的回测，空头那半边收益整个不存在 |
| `board_permission` | 策略池涉及的板块需要什么账户权限 | 科创板/北交所需 20 日日均资产 50 万、创业板 10 万，外加 24 个月交易经历 |
| `dividend_tax` | 复权价把分红按免税还原，个人实际要交 20%/10% | 持股 1 个月以内 20%、1 个月至 1 年 10%、超过 1 年免征；股息率 2% 时就是每年 0.4% —— **和手续费同一个数量级，但没人算** |
| `survivorship` | 退市股在不在样本里 | 只在活到今天的票上回测 → **高估收益** |

按严重程度分组输出，并区分"真的用错规则"和"故意留的取整余量"。

`order_size` 和 `tick_size` 需要成交明细里有 `qty`（股数）/ `price` 列。
**没有这两列时工具会明说"没查"，不会猜。**

哪些规则查了、哪些没查、没查的原因是什么，逐条列在
**[RULE_INVENTORY.md](RULE_INVENTORY.md)**。一个审计工具最危险的失败
不是漏报，是让人以为它查全了。

它在真实项目上查出过什么：**[AUDIT_CASE_01.md](AUDIT_CASE_01.md)** 是一份
完整案例（一个公开的 28 套短线策略项目），里面每个数都由
[`case01_recheck.py`](case01_recheck.py) 生成、数据是该项目**自己发布**的汇总，
任何人能重跑复核。案例里**对它有利的结论也写了**（它的成本模型偏保守）——
一份只挑对自己有利的证据的审计报告，没有资格叫审计报告。
**[AUDIT_CASE_02.md](AUDIT_CASE_02.md)** 审的是另一类对象：一个**把 A 股约束

## 框架档案

```bash
python3 ashare_audit_standalone.py 成交.csv --framework qlib
```

省去自己填假设值。已内置 `qlib` / `rqalpha` / `backtrader`，
各自的默认值来自读它们 main 分支的源码，注明了文件位置（见 `ECOSYSTEM_REPORT.md`）。

**立场：这个工具不是用来"抓框架的错"的。** rqalpha 的涨跌停架构
（从数据源取价而非自己算百分比）和 2023 印花税分段都是对的，报告里写明了。
工具做的是**把你的回测假设和当年的实际规则摆在一起看**。

## 这些规则的出处

全部对着一手资料核过，写在 `ashare_audit_standalone.py` 里：

- 创业板 ±10% → ±20%：**2020-08-24**（注册制改革）
- 科创板 ±20%：**2019-07-22** 开市即是，无历史切换
- ST ±5% → ±10%：**2026-07-06**
- 北交所 ±30%
- 印花税：2023-08-28 起 5bp 单边 / 2008-09-19~2023-08-27 10bp 单边 /
  2008-04-24~2008-09-18 10bp **双边** / 2007-05-30~2008-04-23 30bp 双边
- 熔断日：2016-01-04、2016-01-07（机制 01-01 生效、01-08 暂停，期间触发两次）
- 注册制新股**前 5 个交易日不设涨跌幅**：科创板 2019-07-22 / 创业板
  2020-08-24 / 主板 2023-04-10 起
- 申报数量：买入 100 股整数倍（科创板 200 股起、1 股递增）；单笔上限
  沪深主板 100 万股 / 创业板限价 30 万 / 科创板限价 10 万股
- 风险警示股票单账户单日买入 ≤ 50 万股（当日累计，上交所，2013-01-01 起）
- 卖空：融券是「借入证券并卖出」，只能卖标的名单内的券，且**申报价不得低于
  最新成交价**（提价规则）—— 上交所融资融券交易实施细则第二条/第十二条/
  第二十三条/第三十条
- 板块权限：科创板与北交所「20 个交易日日均资产 50 万 + 交易经历 24 个月」，
  创业板「10 万 + 24 个月」
- 股息红利差别化个人所得税：财税〔2015〕101 号，2015-09-08 起 ——
  持股 1 个月以内 20%、1 个月至 1 年 10%、超过 1 年暂免征收；
  调整前（财税〔2012〕85 号，2013-01-01 起）超过 1 年按 25% 计入 → 5%
- 费用：过户费 0.001% 双边、经手费 0.0341‰ 双边、证管费 0.02‰ 双边、
  佣金起点 5 元/笔、佣金上限 0.3%

二手来源、未核到原文、或查不动的条目，在 RULE_INVENTORY.md 里单独标出来 ——
标了"未核"的不要当成已核。

## 一个细节，因为它正是工具要查的那类错

判定"封板"用**半分容差**，不是取整后精确相等。

原因是**平局**。当 `前收 × (1+幅度)` 正好落在半分上，
pandas / numpy 的 `.round()` 用银行家舍入（就近取偶），而交易所是四舍五入：

| 前收 | 幅度 | 理论涨停价 | `.round(2)` | 交易所 | 真实收盘 |
|---:|---:|---:|---:|---:|---:|
| 4.75 | ±10% | 5.225 | **5.22** | 5.23 | 5.23 |
| 2.10 | ±5% | 2.205 | **2.20** | 2.21 | 2.21 |
| 5.30 | ±5% | 5.565 | **5.56** | 5.57 | 5.57 |

**方向是单边的**：银行家舍入有一半的平局向下取，算出的涨停价低于真实值，
于是"收盘 == 涨停价"不成立 → **漏判涨停**。

平局并不罕见 —— ST 股 ±5%、价格又多是 0.1 的整数倍，很容易凑出半分。
第一版就是取整后精确相等，在 11,354 行交叉比对里漏掉 12 个涨停（1.4%），
其中多数是 ST 股：一个**系统性低估它自己要查的那个问题**的 bug。

改成半分容差之后，与独立构建的参考面板在 11,354 行上
`limit_up` / `limit_down` / `is_st` **三项全部 100% 一致**。

## 不做什么

- 不查未来函数（通用的已有成熟方案：`peekahead`、Freqtrade 内置的 lookahead analysis）
- 不算收益、不评价策略好坏
（多重检验现在做了，见下。）

## 多重检验：试了多少次

上面七项查的是"这笔成交合不合法"。但一份回测哪怕制度规则全对，
只要作者**试了 200 个策略只报最好的那个**，报出来的数字仍然主要是选择的产物。

```bash
python3 ashare_audit_standalone.py --trials 48 --observed-sharpe 2.04 \
    --trial-sharpes 1.15,1.05,1.08,0.45,1.08,1.54,1.47,1.25,1.54,1.13
```

```
  **零技能**假设下，最大 Sharpe 的期望：1.90
  你报告的 Sharpe：2.04   差额：+0.14
  → 只高出不到半个试验间标准差。**大部分**可以由试验次数解释。

  试验次数的代价：
       5 次 → 1.56        50 次 → 1.90
      10 次 → 1.68       200 次 → 2.06
      20 次 → 1.78       500 次 → 2.15
```

用的是极值分布的标准近似（Bailey & López de Prado 的 Deflated Sharpe Ratio
同一个式子）：

$$E[\max] \approx \mu + \sigma\left[(1-\gamma)\Phi^{-1}(1-\tfrac{1}{N})
  + \gamma\,\Phi^{-1}(1-\tfrac{1}{Ne})\right]$$

**两条边界写在输出里，不藏：** 公式假设 N 次试验独立，同一想法的变体高度相关，
所以算出来的是**上界**；而试验次数要算**全部跑过的**，包括调参试过的、
跑完看一眼就删的。
